SCAN&GO AI — START HERE

1. Extract the ZIP.
2. Open the extracted scan-go-ai folder in VS Code.
3. Open Terminal > New Terminal.
4. Run: npm install
5. Copy .env.example to .env
6. For first run, you can leave PayPal and Gemini keys blank.
7. Run: npm run dev
8. Open http://localhost:5173

First milestone: test product search, add-to-cart, total calculation and built-in budget advice.
Then configure PayPal Sandbox credentials and test payment.

Never share or upload your .env file or PayPal Secret to GitHub.
